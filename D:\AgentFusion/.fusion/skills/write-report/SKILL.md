# Write report

## 何时使用
需要向群内汇报工作、写总结、写说明文档或公告时。

## 结构（结论先行）
1. 一句话结论：做成了什么 / 没做成什么。
2. 依据：关键证据（文件、file_id、命令与真实输出）。
3. 细节：只写必要的实现要点与取舍。
4. 下一步：未完成项、风险、需要谁配合。

## 规则
- 中文短句，避免形容词堆砌与空话（「赋能」「闭环」这类词不要用）。
- 每个数字都要有来源；没有数据的判断明确标注为「判断」。
- 长文档写入工作区文件或 room_file_save 落盘，群里只报 file_id + 一句话描述。
- 群内汇报控制在 15 行内。
